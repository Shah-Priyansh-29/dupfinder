## 1. Problem Statement
In multi-user operating systems and local development environments, folders accumulate duplicate files due to repeated downloads, manual backups, and project copies. These duplicates waste expensive disk space and cause confusion. The goal of this project is to build an interactive, non-destructive duplicate file management utility that:
1. Calculates cryptographic MD5 hashes for all files in a target directory.
2. Groups redundant files by identical checksums using Linux pipeline filters (`sort`, `uniq -w 32`).
3. Safely isolates duplicate copies into a designated `_duplicates/` folder without deleting them.
4. Quantifies reclaimed storage space using `du`.
5. Provides a reliable one-step undo capability to restore relocated files.
6. Automates background audit scans on a recurring schedule via `crontab`.

## 5. Features
1. **Compute md5sum for all files**: Computes 128-bit cryptographic MD5 digests for each regular file in the target folder, formatted with size and filenames.
2. **Group duplicates**: Uses `find ... -exec md5sum {} + | sort | uniq -w 32 -D` to isolate identical 32-hex character hashes and display redundant copies grouped together.
3. **Move duplicates to `_duplicates/` (no delete)**: Retains the primary original in `data/testfiles/` and moves extra copies to `data/testfiles/_duplicates/`. Every move is recorded in `logs/moved_files.txt`.
4. **Report space saved (`du`)**: Inspects `_duplicates/` using `du -sh` and `ls -lh` to report total storage recovered.
5. **Undo by moving them back**: Reads `logs/moved_files.txt` and moves files back to their exact original locations, ensuring zero data loss and clean state rollback.
6. **View data**: Lists all active files and count in `data/testfiles/`.
7. **Backup data (`tar.gz`)**: Archives `data/` into `backups/data_YYYYMMDD_HHMMSS.tar.gz`.
8. **View activity log**: Displays the last 15 actions logged to `logs/activity.log`.

## 8. Commands Used & Explanations
- **`md5sum`**: Computes 32-character hexadecimal MD5 hashes. Used to verify byte-for-byte identical content regardless of file name.
- **`sort -k1,1`**: Orders checksum output lexicographically by hash so identical files appear consecutively.
- **`uniq -w 32 -d / -D`**: Evaluates only the first 32 characters (`-w 32`) representing the MD5 hash. `-d` outputs duplicate hashes; `-D` outputs all repeated lines.
- **`find "$DATA" -maxdepth 1 -type f`**: Discovers regular files in the directory without descending into subfolders or scanning `_duplicates/`.
- **`mv`**: Atomically moves redundant files to `_duplicates/` during isolation and back during undo.
- **`du -sh`**: Reports total disk usage in human-readable units (K, M, G).
- **`tar -czf`**: Compresses data directory into a `.tar.gz` archive (`-c` create, `-z` gzip, `-f` archive file).
